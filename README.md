# Messenger 

Веб-приложение для отправки и получения текстовых сообщений в WhatsApp через сервис [GREEN-API](https://green-api.com/).

**Демо:** [https://messenger-sigma-bay.vercel.app](https://messenger-sigma-bay.vercel.app)

## Возможности

- авторизация с использованием `idInstance` и `apiTokenInstance`;
- сохранение данных подключения в `localStorage`;
- создание чата по номеру телефона;
- отправка текстовых сообщений в WhatsApp;
- получение входящих сообщений в реальном времени;
- long polling через метод `receiveNotification` GREEN-API;
- удаление обработанных уведомлений через `deleteNotification`;
- оптимистичное обновление интерфейса при отправке сообщения;
- автоматическая прокрутка чата к последнему сообщению;
- отображение времени отправки сообщений;
- адаптивный интерфейс в стиле WhatsApp;
- обработка ошибок отправки и сетевых ошибок.

## Архитектура

Приложение построено как одностраничное React-приложение.

Основная логика реализована в компоненте `App`:

- управление состоянием авторизации;
- создание и смена активного чата;
- отправка сообщений;
- получение входящих сообщений;
- обработка уведомлений GREEN-API;
- управление состоянием интерфейса.

Для получения входящих сообщений используется long polling. После обработки уведомление удаляется через API, что позволяет продолжать получать следующие сообщения.

## Работа с GREEN-API

Для подключения используются:

- `idInstance`;
- `apiTokenInstance`.

После подключения приложение обращается к API GREEN-API непосредственно из браузера.

Для отправки сообщения используется метод `sendMessage`.

Для получения входящих сообщений используется `receiveNotification`, а обработанные уведомления удаляются через `deleteNotification`.

> Для работы приложения необходима активная учётная запись GREEN-API и соответствующие данные подключения.

## Локальный запуск
**1. Клонировать репозиторий**

```bash
git clone https://github.com/Lyubov15/messenger.git
cd messenger
```

**2. Установить зависимости**

```bash
npm install
```

**3. Запустить сервер**

```bash
npm run dev
```
